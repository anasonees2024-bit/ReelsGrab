# Reels Grab (Android)

زر عائم فوق إنستجرام وفيسبوك: اضغطه، اختر الجودة، ويبدأ التحميل بالخلفية.

## بناء ملف APK بدون Android Studio
1. أنشئ مستودع على GitHub وارفع محتوى هذا المجلد كما هو.
2. تبويب Actions ← Build APK ← Run workflow.
3. بعد انتهاء البناء نزّل ReelsGrab-apk من قسم Artifacts، فك الضغط، وثبّت الملف.

## أو عبر Android Studio
افتح المجلد، انتظر Sync، ثم Build ← Build APK(s).

## بعد التثبيت
افتح التطبيق، فعّل خدمة إمكانية الوصول، واسمح بالعرض فوق التطبيقات.
